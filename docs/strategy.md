# Prize strategy

## Key rules

- Submissions: Oct 1 to **Nov 12, 2026, 12:00 PT**. Judging Dec 1 to 15; winners around Dec 21.
- Build an app that integrates the **PayPal developer platform (sandbox)** with any AI tool. PayPal must be central.
- Submit: text description, public repo with an **open-source license** visible in the About section, setup and run instructions (or a hosted demo), and a **YouTube demo video under 3 minutes**.
- Judges may judge only from the description, images and video, so the video carries a lot of weight.
- Stage 1 is pass/fail (fits the theme, uses the required APIs). Stage 2 scores five equal criteria: **Technological Implementation** (also the first tie-breaker), Design, Potential Impact, Innovation, Presentation.
- One project can win **one Grand or Honorable Mention prize plus one Sponsor prize**.

## Prizes

| Prize | Value | Slots |
| --- | --- | --- |
| Grand: 1st / 2nd / 3rd | $12k / $8k / $5k | 1 each |
| Honorable Mentions: Most Creative, Most Impactful, Best Demo Delivery, Best Use of PayPal + AI, Best Use of Agentic Commerce | $5k | 1 each |
| AG Grid | $5k / $2k / $1k | 1 / 1 / 3 |
| APIMatic | $1k + 6 months subscription | 3 |
| Bryntum | $1k | 3 |
| Channel3 | $1.5k | 1 |
| Render | $1k / $750 / $500 credits | 1 each |

Elastic, Postman, Zapier, KERNEL and Astropods are allowed sponsor tools but have **no prize**.

## Targets

- **Main: Best Use of Agentic Commerce** ($5k). Narrow theme, fits PayPal's current push, and a strong entry also competes for the Grand prizes.
- **Sponsor: AG Grid** (5 winners, $1k to $5k), plus **Channel3** if we pick Idea 1. We can only win one sponsor prize, but using both gives two chances.
- **Fallback: Best Demo Delivery.** Mostly decided by our video.

## How we win

1. Use several PayPal APIs for real (orders, invoices, subscriptions, tracking, webhooks) with a real agent.
2. Ship everything in Docker (`docker compose up`) plus a hosted demo, so judges can run it in one step.
3. A tight video under 3 minutes: problem, who it's for, a full working flow.
4. README, license and run steps done early; missing them fails stage 1.
